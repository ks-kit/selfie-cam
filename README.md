# 美顔カメラ

iPhone と Android の両方で使える、自撮り用の美顔補正カメラ。
ブラウザで動く PWA なので、インストールもアプリストアも要らず、URL を開くだけで使える。

**撮った写真はどこにも送信されない。** カメラ映像の取得も補正も保存も、すべて端末の中だけで完結する。

## 使い方

1. ページを開いて「カメラを起動」
2. 下のプリセットを選ぶ（ナチュラル／しっかり／色白／血色）
3. 「調整」を開くとスライダーで細かく変えられる。気に入った設定は「この設定を保存」でマイ設定になる
4. 白い丸ボタンで撮影 →「保存」

- **画面を長押しすると補正前が見える**（効き具合の確認用）
- 設定は自動で保存され、次回も同じ状態から始まる

### ホーム画面に追加すると使いやすい

**上下のブラウザのバーが消えて全画面になる。** URL を直接開いている間は消えない。

- **iPhone**: Safari で開く → 共有ボタン →「ホーム画面に追加」
- **Android**: Chrome で開く → 右上の「⋮」→「アプリをインストール」
  （文言は Chrome のバージョンにより「インストール」「ホーム画面に追加」のこともある）

### 写真の保存先

| | 保存先 |
|---|---|
| iPhone | 「保存・共有」→ 共有シートの「画像を保存」→ **カメラロール** |
| Android | **Download フォルダ**（ギャラリーの「Download」アルバムに入る） |

**Android で Download になるのは、Web アプリが保存先を選べないため。**
ブラウザのダウンロード先に決まる。カメラの写真と一緒に並べたい場合は
Google フォト → ライブラリ → デバイス内の写真 → **Download** → バックアップをオン。

## 補正の内容

| 項目 | 内容 |
|---|---|
| 肌なめらか | 輪郭を残したまま肌の凹凸だけをぼかす |
| 質感を残す | ぼかしすぎて「のっぺり」するのを防ぐ |
| 肌の明るさ | 肌だけを明るくする（くすみ抜き） |
| 明るさ／コントラスト／彩度／色温度 | 全体のトーン調整 |

目・眉・唇・髪には補正がかからないよう、肌の色を判定して補正範囲を限定している。

## 技術構成

| 要素 | 使っているもの |
|---|---|
| 画像処理 | WebGL2 + 自作の GLSL シェーダ |
| 肌をなめらかにする処理 | バイラテラルフィルタ（横・縦の2パス）＋周波数分離 |
| 肌の判定 | YCbCr 色空間での肌色判定 |
| 保存 | Android はダウンロード、iOS は共有シート |
| 配信 | GitHub Pages（静的ファイルのみ。サーバー処理なし） |

描画は4パス構成。ぼかしだけを低い解像度で計算して負荷を下げ、合成は元の解像度で行うことで
目や髪のディテールを保っている。プレビューは軽さを優先し、シャッターを切った瞬間だけ
カメラのフル解像度に切り替えて処理し直す。

## ファイル

```
index.html          画面
css/style.css       スタイル
js/app.js           カメラ制御・補正パラメータ・撮影・保存
js/renderer.js      WebGL2 の描画パイプライン（4パス）
js/shaders.js       補正シェーダ本体
test-shader.html    シェーダの検証用ページ（実機なしで動作を確認できる）
仕様書.md            設計の経緯と実測値の記録
```

## 開発

ローカルで動かすには HTTPS か localhost が必要（カメラ API の制約）。

```
python -m http.server 8000
```

Android 実機で試す場合は USB 接続して `adb reverse tcp:8000 tcp:8000` を実行すると、
実機の `http://127.0.0.1:8000/` からアクセスできる（localhost 扱いになるため HTTPS が不要）。
